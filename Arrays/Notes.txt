
1. What is a data structure?

A data structure is a way of organizing and storing data in a computer so that we can access and process it efficiently.

Imagine you have five student marks:

80, 90, 70, 60, 100

Without an array, you might store them like this:

int mark1 = 80;
int mark2 = 90;
int mark3 = 70;
int mark4 = 60;
int mark5 = 100;

But what if you have 1,000 students? Creating 1,000 variables is inconvenient.

That's why we use an array.

2. Array definition
An array is a linear data structure that stores a fixed number of elements of the same type, accessed using an index.

Let's break this down.

Linear: Elements are arranged in a sequence.

Same type: An int[] stores integers, a char[] stores characters.

Fixed size: A Java array's length cannot change after creation.

Index: Every element has a position starting from 0.

Java arrays store their elements in consecutive array slots. For primitive int arrays, each element contains an integer value. For arrays of objects, each slot stores a reference to an object.

3. Approach 1 — Brute force
What is brute force?

Brute force is a straightforward way to solve a problem, usually without focusing on optimizing time or memory.

For this problem, create a second array and copy the elements in reverse order.

Algorithm:

Create a new array of the same length.

Start reading the original array from the last index.

Copy each element into the new array from left to right.

Print the reversed array.

Java code — Brute force

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};
        int n = arr.length;

        int[] reverse = new int[n];

        for (int i = 0; i < n; i++) {
            reverse[i] = arr[n - 1 - i];
        }

        System.out.println(Arrays.toString(reverse));
    }
}

4. Approach 2 — Optimal (Two Pointers)
What are two pointers?

Two pointers is a technique where we use two index variables to navigate an array.

For reversing:

left starts at index 0.

right starts at index n - 1.

Swap the elements at those positions.

Move left forward and right backward.

Stop when left >= right.

This reverses the original array without creating another array.

5. Optimal Java code

import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};

        int left = 0;
        int right = arr.length - 1;

        while (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;

            left++;
            right--;
        }

        System.out.println(Arrays.toString(arr));
    }
}

6. Time and space complexity — From zero
What is time complexity?
Time complexity describes how the number of operations grows as the input size N increases.

We use Big O notation, such as O(1), O(N) and O(N²).

Why is optimal time O(N)?

Because we swap approximately N / 2 pairs. Big O ignores constant factors, so O(N/2) becomes O(N).

Why is optimal space O(1)?

Because we use only three extra variables: left, right, and temp. The amount of extra memory does not grow with N.

Interview insight: Both approaches take linear time, but the two-pointer solution is better in auxiliary space because it modifies the array in place.

7. How to explain this in an Infosys interview
I will use the two-pointer technique. I initialize one pointer at the beginning and another at the end of the array. I swap their elements and move both pointers toward the center. I repeat until the pointers meet or cross. The algorithm takes O(N) time and O(1) extra space because I reverse the array in place.
